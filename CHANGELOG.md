# Changelog

All notable changes to the "Neon Loom" VS Code extension will be documented in this file.

---

## [1.0.4] - 2026-07-30

### 🎉 Re-release: Neon Loom

- **Clean re-release** with updated repository name
- Glowing neon color palette: electric orange, cyan, purple, lime green, and gold
- Spinning wheel cursor animation
- Fabric texture background
- Thread count line numbers
- Rainbow bracket pair guides

---

## [1.0.3] - 2026-07-30

### 🎉 Major Update: Rebrand to "Neon Loom"

- Renamed from `weaving-chaos` to `neon-loom`
- New display name: "Neon Loom"
- Updated description to reflect glowing, electric aesthetic
- Added neon/glow keywords for better discoverability

---

## [1.0.2] - 2026-07-29

### ✨ Features Added

- Spinning Wheel Cursor — Smooth, animated cursor that feels like a spinning wheel
- Fabric Texture Background — Woven texture feel in the editor
- Thread Count Display — Line numbers show your "thread count"
- Knitting Pattern Guides — Rainbow bracket pairs like different yarn colors
- Natural Dye Palette — Saffron, indigo, terracotta, and linen colors
