# Changelog

All notable changes to the "Lucent" VS Code extension will be documented in this file.

---

## [1.0.4] - 2026-07-30

### ✨ Major Rebrand: Lucent

- **Renamed** from `neon-loom` to `lucent`
- **New display name:** "Lucent"
- **New repository name:** `lucent-vscode-theme`
- **Updated description** to reflect the "luminous/glowing" theme
- **Updated keywords** to include `lucent`, `luminous`, `light`
- Updated all links to point to the new repository
- Clean CHANGELOG without legacy references

### ✨ Features (Unchanged)

- 🔄 Spinning Wheel Cursor
- 🧵 Luminous Texture Background
- 📊 Thread Count Display
- 📐 Knitting Pattern Guides
- 🎨 Lucent Glow Palette

---

## [1.0.3] - 2026-07-30

### 🎉 Rebrand: Neon Loom

- Renamed from `weaving-chaos` to `neon-loom`
- New display name: "Neon Loom"
- Updated description to reflect glowing, electric aesthetic
- Added neon/glow keywords for better discoverability

---

## [1.0.2] - 2026-07-29

### ✨ Features Added

- Spinning Wheel Cursor — Smooth, animated cursor that feels like a spinning wheel
- Fabric Texture Background — Woven texture feel in the editor
- Thread Count Display — Line numbers show your "thread count"
- Knitting Pattern Guides — Rainbow bracket pairs like different yarn colors
- Natural Dye Palette — Saffron, indigo, terracotta, and linen colors
